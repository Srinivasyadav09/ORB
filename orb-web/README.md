# ORB — Online Raithu Bazaar

A polished React + Vite frontend prototype based on the ORB design direction.

## Run

```bash
npm install
npm run dev
```

## Included

- Public ORB landing page
- Customer login/signup
- Farmer login/signup
- Customer home, products, cart, checkout, orders, order details, account
- Farmer dashboard, verification, products, add/edit product, profile
- Responsive desktop/tablet/mobile layouts
- Product search and category filtering
- Cart quantity controls
- Delivery address selection
- Order status timeline
- Rating CTA

This version is intentionally frontend-only. Connect APIs for authentication, database, payment, maps/location, image upload, farmer verification, orders, notifications and ratings.
